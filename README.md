# 小小計帳本 (TinyLedger)

一個輕量、注重隱私、結合農民曆與進階理財分析的純本地端記帳 PWA 工具，無需安裝任何後端伺服器，打開瀏覽器就能使用。

- **當前版本**：`v1.2.4.0` (2026-08-20)
- **線上體驗 (GitHub Pages)**：[https://ssworld72.github.io/TinyLedger/](https://ssworld72.github.io/TinyLedger/) *(請根據實際網址替換)*

---

## ✨ 主要功能

### 📝 記帳與收支管理
- **一般紀錄**：支援收入、支出的日常記帳，可自訂大類別、小類別與交易對象（例如：個人、家人、特定專案）。
- **固定紀錄**：支援週期性收支設定（如：每月房租、每週固定支出、每年訂閱費），自動產生未來的預期紀錄，省去重複記帳的麻煩。
- **預算控管**：可設定「本月總預算」，系統會根據您的累積支出與剩餘預算，動態顯示即時進度條與超支警告。

### 📅 萬年曆與農民曆整合
- **日曆檢視**：內建美觀的月曆模式，能一目了然每天的收支總計。
- **傳統農民曆**：支援顯示農曆日期、天干地支（八字排盤）、二十四節氣與傳統節慶。
- **國定假日**：自動串接人事行政總處資料，顯示台灣國定假日與休市日，並提供一鍵更新功能。
- **地點定位**：內建 Google Maps Places API 串接功能，記帳時可一鍵定位並記錄消費地點。

### 📊 統計與圖表分析
- **視覺化圖表**：提供甜甜圈圖（各類別佔比）與長條圖（每日/月趨勢），幫助您快速掌握資金流向。
- **多維度篩選**：可根據時間範圍（本月、上月、今年等）、收支類型、大小類別或特定對象進行深度篩選與分析。

### ☁️ 備份與還原
- **GAS 私有雲端備份**：透過 Google Apps Script 將資料加密備份至您專屬的 Google 雲端硬碟，完全掌控您的財務隱私。
- **JSONL 壓縮備份**：一鍵匯出含所有交易紀錄與設定的備份檔，方便您跨設備轉移資料。
- **純離線架構**：所有資料皆使用 IndexedDB 儲存於您的瀏覽器本地端，即使斷網也能正常記帳。

### 🎨 介面與體驗
- **PWA 支援**：支援將網站加到手機桌面，體驗如原生 App 般順暢。
- **深色模式 (Dark Mode)**：內建完整的深色模式，可跟隨系統自動切換，保護您的眼睛。
- **觸控與手勢優化**：針對手機與平板的操作體驗進行深度優化，支援滑動與快速點擊。

## ☁️ 設定私有雲端備份 (GAS Backend)

本系統支援將您的記帳資料加密備份至您私人的 Google 雲端硬碟，達到 100% 的隱私與跨裝置同步。

### 部署教學 (只需設定一次)

#### 第一階段：貼上程式碼
1. 前往 [Google Apps Script](https://script.google.com/)，點選左上角的「＋ 新專案」。
2. 點選左上方預設的「未命名的專案」，將它改名為容易辨識的名稱，例如：`通用_私有雲端備份`。
4. 將本系統提供的 `gas_private_backup.js` 程式碼全部貼上並儲存。

#### 第二階段：部署並設定權限
1. 點擊畫面右上角的藍色按鈕「部署」，選擇「新增部署作業」。
2. 在跳出的視窗中，點擊左上角齒輪圖示，勾選「網頁應用程式」。
3. **【最重要】**：「執行身分」請務必選擇「**我**」，「誰可以存取」請選擇「**所有人**」。
4. 設定好後，按下右下角的「部署」。

#### 第三階段：授權與取得網址
1. (首次部署) 系統會跳出授權視窗，請點擊「授權存取」並選擇您的 Google 帳號。
2. (首次部署) 若出現警告畫面，請點擊左下角「進階」->「前往 (不安全)」，然後點擊「允許」。
3. 授權完成後，複製「網頁應用程式」下方的「**網址 (URL)**」。
4. 回到計帳本的「系統設定」頁面，將網址貼入 GAS 雲端備份的格子中，即可完成綁定！

> 💡 **提示**：如果您之前已經為其他專案部署過通用版的 GAS 備份腳本，您可以直接貼上同一個網址！系統會自動在您的雲端硬碟中依照專案名稱分門別類儲存，完全不會互相覆蓋。

## 🗺️ 設定 Google Maps API (選填)

本系統支援 Google Maps Places API，讓您在記帳時可以一鍵搜尋並記錄消費地點。

### 申請與綁定教學 (只需設定一次)

#### 第一階段：建立 Google Cloud 專案
1. 前往 [Google Cloud Console](https://console.cloud.google.com/)，使用您的 Google 帳號登入。
2. 點擊頂部導覽列的「**選取專案**」下拉選單，再點擊右上角的「**新增專案**」。
3. 輸入一個容易辨識的專案名稱（例如：`TinyLedger Map`），然後按「建立」。
4. 建立完成後，確認目前已選擇到該專案（頂部應顯示您剛建立的專案名稱）。

#### 第二階段：啟用 API 並建立金鑰
1. 在左側選單中點擊「**API 和服務**」>「**程式庫**」。
2. 在搜尋框中搜尋並啟用以下兩個 API：
   - **Places API (New)**
   - **Maps JavaScript API**
3. 回到左側選單，點擊「**API 和服務**」>「**憑證**」。
4. 點擊頂部的「**+ 建立憑證**」>「**API 金鑰**」，系統會自動產生一組金鑰。
5. 在彈出的視窗中，先**複製**這組金鑰（待會要貼回 APP）。

#### 第三階段：（建議）限制金鑰 + 貼回設定
1. 在剛才的彈出視窗中，點擊「**編輯 API 金鑰**」（或在憑證列表中點該金鑰的鉛筆圖示）。
2. 向下捲動到「**API 限制**」區塊，選擇「**限制金鑰**」，然後下拉勾選您剛才啟用的上述兩個 API 進行綁定。
3. 按下「**儲存**」即可。
4. 最後，將複製好的金鑰貼回設定頁面的「**Google Maps API Key**」輸入框中，大功告成！

> 💡 **費用說明**：Google 每月提供 200 美元的免費地圖額度，對於一般個人記帳用途來說，完全不需擔心費用問題。填寫帳單資訊僅為 Google 的防濫用認證步驟。

## 💡 常見問題 (FAQ)

### Q: 我的記帳資料儲存在哪裡？會不會外洩？
**不會外洩。**
本系統採用「純前端」架構，所有的記帳紀錄與設定都會加密儲存在您瀏覽器的本地資料庫 (IndexedDB) 中。我們沒有架設任何中心化資料庫來收集您的資料，因此您的財務隱私絕對安全。

### Q: 如果我換手機或換電腦，資料該怎麼轉移？
您有兩種方式可以無痛轉移資料：
1. **手動匯出/匯入**：在舊設備的設定頁面點擊「匯出備份」，會下載一個 `.jsonl` 檔案，將此檔案傳送到新設備後「匯入」即可。
2. **私有雲備份 (推薦)**：您可以透過設定頁面中的「GAS 雲端備份」教學，將帳本綁定您自己的 Google 雲端硬碟。在舊設備點擊「備份至私有雲」，接著在新設備貼上相同的網址並點擊「從雲端還原」，就能一秒找回所有資料！
